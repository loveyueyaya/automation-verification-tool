## 2. shim 设计说明

目录名 `P2-layers` 含连字符，**不能作为包名 import**（`import P2-layers.contracts` 非法）。
因此 shim 不用 `from ... import *`，而是：

```python
_spec = importlib.util.spec_from_file_location(
    __name__, _NEW_INIT, submodule_search_locations=[_NEW_PKG])
_mod = importlib.util.module_from_spec(_spec)
sys.modules.pop(__name__, None)
sys.modules[__name__] = _mod
_spec.loader.exec_module(_mod)
```

即**整体替换 `sys.modules['contracts']`**。效果：

- `from contracts import SourceEnum` ✅
- `from contracts.state_hash import state_hash` ✅（子模块从新目录解析；
  注意 `contracts.state_hash` 这个名字被同名函数遮蔽，但 `import` 语句走
  `sys.modules['contracts.state_hash']`，不受影响——56 测试已覆盖该写法）
- CPython `importlib._bootstrap._InstalledSafely` 注释明确支持这种 sys.modules 替换。

失败兜底：新包缺失时直接 `raise ImportError`（不会静默退回旧实现）。
