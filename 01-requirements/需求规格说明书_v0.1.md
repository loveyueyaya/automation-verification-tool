# 需求规格说明书 v0.1（精简版）

- 日期：2026-09-16 ｜ 状态：待评审 ｜ 依据：运行环境报告 v0.1 + 架构设计 v3
- 项目定位：Windows 桌面 **UI 自动化测试程序**——本地确定性引擎（感知/定位/执行/校验/审计）+ LLM 决策层（意图规划，不碰坐标），三工具协作：被测程序（cookie_sync 类）＋测试控制台＋执行引擎（ui-toolbox）。

## 1. 功能边界

**支持（v1 范围）**
- Windows 桌面 UI 自动化：截图（dxcam/mss/BitBlt）、PaddleOCR GPU 识别、控件树（UIA）、窗口/句柄枚举
- 定位：句柄 > 控件树 > 缓存坐标 > OCR（仅校验，不做坐标来源）
- 注入：SendInput / 句柄直投 / WM_CHAR，由环境适配层按 EnvProfile 自动路由
- 审计：全链路 trace（毫秒时间戳）、坐标来源归因（src/conf/chain）、可回放报告
- 环境适配：注入/截图路由 + 声明式降级表 + 环境探测缓存
- 回归：三工具 smoke 门禁（P3）
- 被测对象：本地 exe/console/浏览器窗口（cookie 迁移类业务流程）

**明确不做（v1 范围外，防 P2 盲目扩展）**
- 移动端（iOS/Android）、macOS/Linux
- Web 跨平台 UI 自动化（浏览器内一律走 CDP 专用通道，不依赖全局注入）
- 视觉模型训练（YOLO 可插拔，默认模板匹配 + UIA）
- 压测/性能基准工具、多用户/权限管理系统
- 非 Windows 专属 API 的跨平台抽象

## 2. 兼容性矩阵

| 维度 | 支持范围 | 说明 |
|---|---|---|
| Windows | 10 22H2+ / 11 | 当前实测：11 22631 |
| DPI | 100%~200% 缩放 | 坐标契约物理像素，逻辑坐标仅经 dpi 转换 |
| UIA 层级 A | 原生 Win32 控件 | 句柄+UIA 全量（控件树/属性/事件） |
| UIA 层级 B | Chromium/Electron | 部分：需 --force-renderer-accessibility 或 CDP 通道 |
| UIA 层级 C | 自绘/游戏画面 | 仅 OCR（无控件树，定位降级语义锚点） |
| GPU | NVIDIA CUDA（算力≥6.1） | PaddleOCR GPU；无 GPU 降级 CPU（限区域，慢 5-10 倍） |
| 浏览器 | Chrome / Edge / 360se | CDP 调试端口（cookie_sync 已用 9222） |

## 3. "完全离线"明确约束

**定义**：代码执行 / 文件存储 / OCR / 工具链 100% 本地；**LLM 决策层不要求本地**。

| 项 | 决策 |
|---|---|
| 是否全程断网 | **否**。核心自动化（感知/定位/执行/校验/审计）断网完全可用；仅 LLM 决策需网络（云端模式） |
| LLM 后端 v1 | 云端豆包 API（现有能力）；接口已抽象 `llm_client` 双后端 |
| LLM 后端 v2（可选） | 本地 ollama（如 qwen2.5:7b，Q4 约 4.7GB）——关断云端后降级纯规则决策（缓存+模板），不瘫痪 |
| 模型资源 | PaddleOCR 已装（paddlepaddle-gpu 3.3.1 + paddleocr 3.7.0，含 CUDA 库，约 1.5GB） |
| 存储路径 | 模型/缓存/大文件 → **D:\models\ 或 F:\**（C 盘仅剩 113.9GB）；程序本体 → ui-toolbox 技能目录 |

**验收口径**：拔网线后，除"LLM 决策"外全部功能可用；`llm_client` 配置 `backend=none` 时系统不报错、按规则决策继续运行。
