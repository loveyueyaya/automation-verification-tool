# 需求规格说明书 v0.2（精简版）

- 日期：2026-09-17 ｜ 状态：待评审 ｜ 依据：v0.1 + 用户口述澄清（P2-1）
- 项目定位：Windows 桌面 **UI 自动化测试程序**——本地确定性引擎（感知/定位/执行/校验/审计）+ LLM 决策层（意图规划，不碰坐标），三工具协作：被测程序（cookie_sync 类）＋测试控制台＋执行引擎（ui-toolbox）。
- 术语澄清：本文中 **v1 / v2 指 LLM 后端演进方向，不是文档版本**。

## 0. 业务场景（v0.2 新增，用户口述）

| 项 | 内容 |
|---|---|
| 被测程序 | cookie_sync 类（cookie 迁移工具） |
| 目标窗口 | Chrome / Edge / 360se（浏览器窗口） |
| 不做场景 | 移动端、macOS/Linux、游戏画面、跨平台抽象 |

## 1. 功能边界

**支持（v1 范围）**
- Windows 桌面 UI 自动化：截图（dxcam/mss/BitBlt）、PaddleOCR GPU 识别、控件树（UIA）、窗口/句柄枚举
- 定位：句柄 > 控件树 > 缓存坐标 > OCR（仅校验，不做坐标来源）
- 注入：SendInput / 句柄直投 / WM_CHAR + **浏览器一律走 CDP 专用通道**，由 env_adapter 按 EnvProfile 自动路由
- 审计：全链路 trace（毫秒时间戳）、坐标来源归因（src/conf/chain）、可回放报告
- 环境适配：注入/截图路由 + 声明式降级表 + 环境探测缓存
- 被测对象：本地 exe / 浏览器窗口（cookie 迁移类业务流程）

**明确不做（v1 范围外）**
- 移动端（iOS/Android）、macOS/Linux、游戏画面
- 视觉模型训练（YOLO 可插拔，默认模板匹配 + UIA）
- 压测/性能基准工具、多用户/权限管理系统
- 非 Windows 专属 API 的跨平台抽象

## 2. 兼容性矩阵

| 维度 | 支持范围 | 说明 |
|---|---|---|
| Windows | 10 22H2+ / 11 | 当前实测：11 22631 |
| DPI | 100%~200% 缩放 | 坐标契约物理像素，逻辑坐标经 dpi 转换 |
| UIA 层级 A | 原生 Win32 控件 | 句柄+UIA 全量（控件树/属性/事件） |
| UIA 层级 B | Chromium/Electron | 需启用辅助树；**--force-renderer-accessibility 由 env_adapter 负责**：探测到 Chromium 窗口未开辅助树时，由环境适配层附加该启动参数（新启进程）或经 CDP 开启（已运行进程） |
| UIA 层级 C | 自绘/游戏画面 | 仅 OCR（无控件树，定位降级语义锚点） |
| GPU | NVIDIA CUDA 算力≥6.1 | 型号：GTX 1050/1060/1650 及以上、RTX 全系列；PaddleOCR GPU；无 GPU 降级 CPU（限区域，慢 5-10 倍） |
| 浏览器 | Chrome / Edge / 360se | CDP 调试端口（cookie_sync 已用 9222） |

**CDP 通道归属**：浏览器窗口的注入/读取一律走 CDP 专用通道，**归属 env_adapter 的注入路由层**（input_router）——对浏览器窗口不做全局 SendInput/句柄注入，避免命中 Chromium 渲染层坐标偏移。

## 3. "完全离线"约束（v1/v2 分列）

**定义**：代码执行 / 文件存储 / OCR / 工具链 100% 本地；**LLM 决策层按后端演进**。

| 项 | 决策 |
|---|---|
| 是否全程断网 | **否**。核心自动化（感知/定位/执行/校验/审计）断网完全可用；仅 LLM 决策需网络 |
| LLM 后端 v1（当前） | **云端豆包 API**（现有能力）；接口已抽象 `llm_client` 双后端 |
| LLM 后端 v2（未来可选，暂不实施） | **本地 ollama**（如 qwen2.5:7b，Q4 约 4.7GB）；关断云端后降级纯规则决策（缓存+模板），不瘫痪 |
| 本地模型区分 | **PaddleOCR（本地视觉识别）= 已装**（paddlepaddle-gpu 3.3.1 + paddleocr 3.7.0，GPU 加速，约 1.5GB）；**ollama（本地 LLM）= 未装**，v2 可选。两者完全不同，不得混淆 |
| 存储路径 | **默认 F 盘**（模型/缓存/大文件）；C 盘只放程序本体 |

**验收口径**：拔网线后，除"LLM 决策"外全部功能可用；`llm_client` 配置 `backend=none` 时系统不报错、按规则决策继续运行。
