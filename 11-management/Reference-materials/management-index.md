# 11-management - 项目管理与规划

## 用途

存放**项目级管理与规划类文档**：进度、开发前盘点、阶段任务规划。
与其它目录的边界：本目录只放"管项目"的文档，不放需求/架构/设计/代码/测试/环境证据。

## ⚠ 平台上下文压缩风险与本目录的存在意义（2026-09-19 用户说明）

WorkBuddy 平台因**优惠到期、对话中断、切换大模型**等情形，会对会话做**上下文压缩**，
导致模型对项目历史"记忆错乱"（细节丢失、状态张冠李戴、旧结论当新结论）。

**用户对策**：创建 `F:\自动化验证工具\11-management`，把项目进度、裁定、规划等**持久事实**全部落盘在此，
作为**跨平台、跨模型的唯一状态源**——即使更换平台（例如改用豆包）或开全新模型会话，
只要读本目录即可恢复项目全貌：

| 需要什么 | 读哪个文件 |
|---|---|
| 入口/目录说明 | 本文件 `management-index.md` |
| **当前状态与裁定（最新）** | `接下来的任务.txt` |
| 环境与能力全量实测 | `本地离线自动化测试工具_开发前盘点_最新版.md（v1+v2 合并版，2026-09-19 23:5x 起）` |
| 结构化进度速览 
**约定**：模型自身的对话记忆**不作为权威依据**；一切"当前状态 / 裁定"以本目录落盘文件为准；
重要裁定与状态变更必须**当场写回本目录**，不得只留在对话里。
