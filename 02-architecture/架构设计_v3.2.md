## 二、select_flow 5 流（补 LLM 前提）

| 流 | 触发条件（按序短路） |
|---|---|
| HUMAN | failure 非空 且 level==STRONG 且 retries >= 2 |
| EXCEPTION | failure 非空（STRONG 但 retries<2，或弱校验失败） |
| CACHE | cache_hit 且 light_check 通过 且 exact_repeat |
| NORMAL | cache_hit 且 light_check 通过 但非 exact_repeat |
| LLM | diff 为空或 significant；**仅在 cache_hit=False 时生效（cache_hit=True 时由前两行短路）** |

规则顺序（纯函数，可单测）：
1. failure 非空 → HUMAN / EXCEPTION
2. cache_hit 且 light_check → CACHE / NORMAL
3. diff 为空或 significant **且 cache_hit=False** → LLM
4. 其他 → NORMAL

`light_check`：目标元素指纹仍在 + 窗口 rect 未变；`exact_repeat`：同 state_hash + 同 target_element_id + 同 action。

## 三、元素 id 双用途（独立函数，不变）

`elem_s:{semantic}_p:{control_path}_h:{handle}`，空段一律写 `none`：

| 用途 | 函数 | 优先级 |
|---|---|---|
| 定位用 | `resolve_for_action(eid)` | L1 handle > L2 control_path > L3 semantic |
| 缓存键用 | `resolve_for_cache(eid)` | L3 semantic > L2 control_path > L1 handle |

## 六、P1 越界实现标记与迁移原则（建议修 6）

以下函数出现在 P1 的 `scripts/env.py`，按分层属于 P2 层——**P1 越界实现，MIGRATION.md 已标记**：

| 函数 | 归属层（P2） | 说明 |
|---|---|---|
| `env.pick_target` | 层3 perception | 目标窗口选择（含 .noise 抖动） |
| `env.wait_window_ready` | 层3 perception | 窗口就绪等待（已含 LRESULT 修复） |
| `env.process_count` | 层5 execution | 进程计数 |
| `env.port_listen` | 层5 execution | 端口监听检查 |

**迁移原则（具体化）**：
1. **按函数逐个 git mv** 到目标层模块（如 `env.pick_target` → `perception\element_detect.py::pick_target`）
2. `env.py` 作为历史文件**保留在 P1 目录（不删）**
3. P2-layers 下用**新模块**承载迁移后的函数（行为不变，import 指向新路径）
4. 迁移完成后 MIGRATION.md 记录对照表，P1 目录最终只保留 MIGRATION.md
